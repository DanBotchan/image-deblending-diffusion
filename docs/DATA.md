# Data preparation

The paper evaluates 300 Fruit--Animal pairs and 100 held-out Vehicle--Flower pairs from the BIDeN benchmark. The exact CSV manifests, prompts, alpha coefficients, and random seeds are included under `manifests/`; their release hashes are in `manifests/SHA256SUMS`. `SOURCE_SHA256SUMS` records the original internal files before unused machine-local provenance columns were removed. Source images remain subject to their upstream terms and are not copied here.

Stage-1 annotation CSVs use these columns:

```text
pair_id,img1_path,img1_class,img1_prompt,img2_path,img2_class,img2_prompt,
a,b,c,d,e,f,z_seeds
```

Image paths are relative to `DEBLEND_DATA_ROOT`. The six alpha coefficients encode the polynomial alpha map; scalar files set only the constant coefficient. `z_seeds` is a Python-style list containing at least three integer seeds.

Expected paper files:

- `dataset.csv`: known scalar, alpha 0.5.
- `dataset_random_alpha_scalar.csv`: unknown scalar sampled in [0.2, 0.8].
- `dataset_random_alpha_map.csv`: unknown polynomial spatial alpha maps.

The Stage-2 manifest is generated by `scripts/select_candidates.py`; do not hand-edit it. It freezes the ground-truth-free candidate decision and preserves the exact Stage-1 pair/sample identifier and seed.

`manifests/auto_prompts/dataset_random_alpha_map_auto.csv` is the spatial manifest with both prompts replaced by the frozen Qwen2-VL output for pairs 0-99 (all other columns unchanged); the raw VLM replies are stored next to it.

A deterministic script that rebuilds the image pairs from the BIDeN source images is not included yet; the manifests above pin the exact pairs, alphas and seeds.

## Validate or copy a prepared dataset

```bash
python scripts/prepare_dataset.py --source-root /path/to/prepared/BID_eval_v2 \
  --output-root "$PWD/data_external/BID_eval_v2"
export DEBLEND_DATA_ROOT="$PWD/data_external/BID_eval_v2"
```

Use `--split generalization` for the prepared Vehicle–Flower pairs. Add `--check-only`
to validate without copying. The main pipeline reads only `img1_path` and `img2_path`;
it synthesizes its measurements using the manifest alpha coefficients. The setup command
copies those source images without resizing or re-encoding them. It does not download the
dataset or recover pair identities from the original upstream collection.

## Prepared source-pair archives

The prepared release archives contain only the paired source PNGs required by the
main pipeline: `BID_eval_v2.tar.gz` (600 images) and `BID_generalization.tar.gz`
(200 images). After obtaining the archives and their `SHA256SUMS`, extract them with:

```bash
sha256sum -c SHA256SUMS
mkdir -p data_external
tar -xzf BID_eval_v2.tar.gz -C data_external
tar -xzf BID_generalization.tar.gz -C data_external
export DEBLEND_DATA_ROOT="$PWD/data_external/BID_eval_v2"
```

These archives have been prepared locally under `outputs/dataset_release/`;
a public hosting URL still needs to be added to the README before public dataset setup
is complete. They preserve the prepared source pixels without re-encoding.
