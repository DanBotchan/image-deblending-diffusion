In short

Two images from one prior

Deblending becomes a joint inverse problem. Diffusion posterior sampling recovers both full source images and the alpha map together, from a single pretrained model.

Prompts settle the ambiguity

One blend has many valid splits. A short text prompt per source, used with cross-negative guidance, tells the sampler which content belongs where.

Coarse in latent space, fine in pixels

Stable Diffusion separates the semantics at 512 × 512. A pixel-space ImageNet diffusion model then restores texture and removes VAE artifacts at 256 × 256.

No training, no ground truth

Nothing is fine-tuned. Three candidate decompositions are sampled and PickScore picks one, so the whole pipeline runs without any reference images.

Abstract

Image deblending is the task of decomposing a composite image back into its source images, which is an ill-posed problem, as a single blended image can be decomposed into multiple plausible source layers. While diffusion models are often used to solve inverse problems, they typically address single-output reconstruction problems. In this work, we formulate deblending as a joint inverse problem, employing diffusion posterior sampling to simultaneously reconstruct two source images, demonstrating that a single diffusion prior is expressive enough to disentangle two full images at once rather than just one. Drawing inspiration from human perception, where semantic understanding helps disentangle visual inconsistencies, we propose a training-free framework that leverages text prompts to constrain this solution space. We address the blind deblending task through a two-stage architecture: text-guided latent diffusion performs semantic separation using prompts as high-level cues, followed by a pixel-space refinement to recover fine details. Stochastic sampling produces multiple plausible decompositions that can be ranked without ground truth. Extensive experiments show that our training-free method achieves state-of-the-art results on unseen domains and extends to spatially-varying alpha maps, while remaining competitive with supervised baselines on standard scalar blending benchmarks.

The forward model

Six numbers describe the blend

The observed image is a per-pixel mix of two sources. Instead of a free value per pixel, which could encode edges, the alpha map is a smooth second-order polynomial over normalized coordinates. The sampler estimates these six coefficients along with the two images. Try them here on the teaser sources.

y = α ⊙ x¹ + (1 − α) ⊙ x²
α(ū, v̄) = a + bū + cv̄ + dūv̄ + eū² + fv̄²
Method

A two-stage, training-free pipeline

Both stages run the same guided step: denoise each source, re-blend with α, and update both samples from the data-consistency gradient. Stage 1 also updates the α coefficients every k = 5 steps; Stage 2 keeps α fixed and uses no prompts.

  1. 01 · Initialize

    Start from the blend

    Encode y, duplicate it into two branches, and add noise to an intermediate step ts. The layout of the mixture survives while the branches diverge.

  2. 02 · Stage 1

    Separate semantics

    Stable Diffusion v1.4 with cross-negative prompting: each branch uses its own prompt as positive and the other's as negative. Consistency with y is enforced in pixel space, and α is optimized alongside the sources.

  3. 03 · Select

    Pick a candidate

    Three seeds give three decompositions. A permutation-invariant PickScore ranking against the prompts picks one, using no ground truth.

  4. 04 · Stage 2

    Refine in pixels

    Re-noise the selected pair to tr < ts and resample with a 256 × 256 ImageNet DDPM, unconditional and with α fixed, recovering texture and correcting VAE artifacts.

The full pipeline takes about 50.6–71.0 minutes per input on one NVIDIA RTX 3090.
